## 0. Запуск живого интерфейса (прототип)

Прототип — статичный HTML-файл, серверная логика не требуется. Запуск через встроенный Python-сервер.

### Запуск

```bash
git clone https://github.com/vavasimioki/armeta_test.git
cd armeta_test
./serve.sh
```

Откройте **http://localhost:8080** в браузере. Остановка — `Ctrl+C`.

Если порт занят:

```bash
lsof -ti:8080 | xargs kill -9
```
